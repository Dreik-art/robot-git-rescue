1. Команда clone нужна для создания локальной копии репозитория с его историей
2. Команда fetch загружает изменения из репозитория и показывает пользователю актуальные изменения, при этом не трогая локальую рабочую папку. Команда pull не только загружает изменения, но и соединяет их, обновляя при этом локальный репозиторий.
