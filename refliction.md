1.Команда clone создает локальную копию репозитория с его историей. 
2.Команда fetch загружает данные с удаленного репозитория, добавляет их в локальный но не сливает с текущей рабочей векто. А команду  pull делает то же самое, но и объединяет загруженные изменения с текущеё локальной веткой.
3.Конфликт возникает потому что Git получает два версии файла. Он не человек и у него нет алгоритма, способного решить, какая версия файла верная, поэтому и возникает конфликт.
4Благодаря первому способу мы просто возвращаем файл в состояние последнего коммита, второй восстанавливает рабочий файл из подготовленного состояния, а третий - создать новый коммит, который отменяет последний ошибочный.
